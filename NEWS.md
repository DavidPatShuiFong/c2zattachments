# c2zattachments (development version)

* Fetch collections from the Zotero API using credentials entered in the
  sidebar or read from the `ZOTERO_USER` and `ZOTERO_API` environment
  variables on startup.
* Fetch items and attachment metadata for selected collections.
* Download selected attachments as a ZIP file.
* Friendly validation messages guide the user when credentials or collection
  selections are missing.
